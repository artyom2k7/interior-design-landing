# Interior Design Agency Landing Page

A sleek, elegant, and modern multi-section landing page designed for an interior design company. Built using mobile-first responsive web layouts and state-driven interactive web components.

## Technologies Used
- **HTML5**: Semantic document structure, forms, mobile viewport optimization (`meta viewport`).
- **CSS3**: Custom font integration, fixed sidebar navigation (with mobile top-bar fallback), CSS Media Queries, element-level hover effects, grayscale filters, and independent box-sizing models.

## Key Features
- **Fully Responsive Layout**: Seamlessly scales from large desktop monitors down to smartphones (under 992px) using advanced CSS breakpoints.
- **Fixed Sidebar Menu**: Persistent desktop navigation block providing immediate layout accessibility, converting into a flexible top-bar navigation grid on mobile screens.
- **Interactive Gallery & Cards**: Team showcase with custom interactive CSS grayscale toggle on hover.
- **Pricing Tables**: Styled 'Basic' and 'Pro' tariff blocks built with robust CSS layout modules that stack vertically on mobile viewports.
- **Integrated Contact Block**: Full-width stylish input fields and responsive submission components.
