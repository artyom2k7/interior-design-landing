# Interior Design Agency Landing Page

A sleek, elegant, and modern multi-section landing page designed for an interior design company. Built using responsive web layouts and state-driven interactive web components.

## Technologies Used
- **HTML5**: Semantic document structure, forms, and buttons.
- **CSS3**: Custom font integration, fixed sidebar navigation, element-level hover effects, grayscale filters, and independent box-sizing models.

## Key Features
- **Fixed Sidebar Menu**: Persistent navigation block providing immediate layout accessibility.
- **Interactive Gallery & Cards**: Team showcase with custom interactive CSS grayscale toggle on hover.
- **Pricing Tables**: Styled 'Basic' and 'Pro' tariff blocks designed using CSS inline-block modules.
- **Integrated Contact Block**: Full-width stylish input fields and submission components.
